# Project Scope Analysis

Tools and templates for clearly defining project requirements, understanding stakeholder needs, and establishing success metrics.

## What's Inside

- **project-charter-template.md** - Start here for a new project. Defines goals, scope, stakeholders, and timeline
- **stakeholder-analysis.xlsx** - Map key players, their interests, and influence levels
- **scope-validation-checklist.md** - Verify your scope is realistic and well-defined before starting

## Why This Matters

Poor scope definition leads to misaligned expectations, budget overruns, and failed implementations. These templates help you avoid that by:

1. **Clarifying the "why"** - Articulating the business/educational problem being solved
2. **Defining boundaries** - What's in scope, what's out, and what might be phase 2
3. **Identifying stakeholders** - Who needs to be involved and when
4. **Setting success criteria** - How you'll know the project actually worked

## Getting Started

1. **New Project?** Start with the [Project Charter Template](project-charter-template.md)
2. **Complex stakeholder groups?** Use the [Stakeholder Analysis Worksheet](stakeholder-analysis.xlsx)
3. **Ready to validate?** Run through the [Scope Validation Checklist](scope-validation-checklist.md)

## Tips

- Schedule 1-2 hour scope definition sessions with your core team and key stakeholders
- Revisit your scope at each major milestone - sometimes it needs to evolve
- Keep scope documents visible and reference them during decision-making
- When scope creep happens (it will), use these templates to formally assess the impact
